## #hmg-개발 메시지

**개발 환경 세팅 완료 (승환 맥북 기준)**
• 차량 앱: Java, AGP 8.8.2 / Gradle 8.10.2 / Vehicle SDK 2.3.2, **JDK 21 필요**
• 폰 앱: Flutter 3.47 (Android·iOS 빌드 확인)
• Pleos 에뮬레이터 v2.1.0에서 Vehicle SDK로 실내 온도·배터리 실제 조회 확인

• 권한은 `android.car.permission.*`이 아니라 `pleos.car.permission.*`을 써야 동작함
