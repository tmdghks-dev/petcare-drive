# 에뮬레이터 테스트 명령어

에뮬레이터 두 개를 같이 켜면 `adb`가 기기를 못 고르니 항상 `-s`로 지정한다.
- 차량(Pleos): `emulator-5554`
- 폰: `emulator-5556`

## 에뮬레이터 켜기
```bash
~/Library/Android/sdk/emulator/emulator -avd Pleos_Connect_v2.1.0 -no-snapshot-load
~/Library/Android/sdk/emulator/emulator -avd Medium_Phone_API_37.0 -no-snapshot-load
```

## 연결된 기기 확인
```bash
~/Library/Android/sdk/platform-tools/adb devices -l
```

## 차량 앱
```bash
# 설치·실행 (car-app 폴더에서)
JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home ANDROID_SERIAL=emulator-5554 ./gradlew installDebug

# 짖음 보내기 → 알림·조명·음악 동시 실행 (대기 화면에서만 반응)
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.BARK

# 진정 완료
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.CALM

# 앱 강제 종료 후 처음부터
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am force-stop ai.petcare.drive.car
```

## 폰 앱
```bash
# 실행 (phone-app 폴더에서)
flutter run -d emulator-5556
```

## 시연 영상 다시 녹화
```bash
zsh docs/demo/record-car-demo.sh     # → docs/demo/car-app-demo.mp4
zsh docs/demo/record-phone-demo.sh   # → docs/demo/phone-app-demo.mp4
```

## 문제 해결
- `adb: more than one device/emulator` → 명령에 `-s emulator-5554`(차량) 또는 `-s emulator-5556`(폰)을 붙인다
- 짖음을 보내도 화면이 그대로 → "함께 탈 아이 선택" 화면이면 무시된다. "이 아이와 출발하기"를 먼저 누른다
- Gradle이 JDK 25로 실패 → Android Studio에서 Gradle JDK를 21로 지정
