# 에뮬레이터 테스트 명령어

에뮬레이터 두 개를 같이 켜면 `adb`가 기기를 못 고르니 항상 `-s`로 지정한다.
- 차량(Pleos): `emulator-5554`
- 폰: `emulator-5556`

## 에뮬레이터 켜기
```bash
~/Library/Android/sdk/emulator/emulator -avd Pleos_Connect_v2.1.0 -no-snapshot-load
~/Library/Android/sdk/emulator/emulator -avd Medium_Phone_API_37.0 -no-snapshot-load
```

## 연결된 기기 확인
```bash
~/Library/Android/sdk/platform-tools/adb devices -l
```

## 차량 앱
```bash
# 설치·실행 (car-app 폴더에서)
JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home ANDROID_SERIAL=emulator-5554 ./gradlew installDebug

# 목적지 도착 → ① 펫케어 시작 화면에 "목적지에 도착했어요"
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.ARRIVE

# 짖음 보내기 → 알림·조명·음악 동시 실행 (펫케어 시작 뒤에만 반응)
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.BARK

# 진정 완료 → 대기 화면으로 돌아가며 한 줄 요약
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.CALM

# 위험 → ④ 위험 화면 (실내 온도를 29.5°C로 가정. 달이 적정 22~24°C보다 3°C 넘게 높으면 위험)
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.DANGER --ef temp 29.5

# 위험 해제 → 실제 차량 온도로 돌아가고 ② 대기에 "다시 안전해졌어요"
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.SAFE

# 주행 중 휴식 알림: 60분 달린 것으로 → 첫 알림 (음성 + 위쪽 배너)
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.DRIVE --ei min 60

# 이어서 90분 → 두 번째 알림 "오래 참고 있어요"
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.DRIVE --ei min 90

# P로 5분 쉰 것으로 → "잘 쉬었어요. 다시 출발해요!" 후 시간 초기화
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am broadcast -a ai.petcare.drive.car.REST

# 앱 강제 종료 후 처음부터
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell am force-stop ai.petcare.drive.car
```

## 폰 앱
```bash
# 실행 (phone-app 폴더에서)
flutter run -d emulator-5556
```

## 시연 영상 다시 녹화
```bash
zsh docs/demo/record-car-demo.sh     # → docs/demo/car-app-demo.mp4
zsh docs/demo/record-phone-demo.sh   # → docs/demo/phone-app-demo.mp4
```

## 문제 해결
- `adb: more than one device/emulator` → 명령에 `-s emulator-5554`(차량) 또는 `-s emulator-5556`(폰)을 붙인다
- 짖음을 보내도 화면이 그대로 → ① 펫케어 시작 화면이면 무시된다. "펫케어 시작"을 먼저 누른다
- Pleos 에뮬레이터에서 앱은 오른쪽 1682×1210 영역에만 그려진다 (왼쪽은 차량 화면)
- Gradle이 JDK 25로 실패 → Android Studio에서 Gradle JDK를 21로 지정
