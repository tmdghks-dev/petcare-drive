# 짖음 감지 구현 가이드 (C-05)

차량 마이크로 약 1초마다 소리를 듣는다. 개 짖음이 들리면 지금의 adb `BARK` 신호와 같은 일(③ 달래는 중)을 한다. 1분 동안 조용하면 `CALM`과 같은 일(② 대기 + "진정했어요")을 한다.

## 동작 한눈에

```
마이크 ─ 0.975초씩 ─▶ YAMNet (소리 521종 점수) ─▶ 개 소리 7종 중 가장 높은 점수
    0.3 이상이 2번 연속 (약 2초)  → onBark()  → ③ 달래는 중
    1분 동안 0.3 미만            → onQuiet() → ② 대기 + "진정했어요"
```

- **모델:** 구글 YAMNet을 쓴다. `app/src/main/assets/yamnet.tflite`에 이미 있고, 따로 학습시킬 필요는 없다.
- **라이브러리:** MediaPipe Audio `com.google.mediapipe:tasks-audio:1.0.0`. 구글 공식 예제가 쓰는 버전이다.
- **소리:** 저장하지 않는다. 점수만 보고 버린다.
- **adb 신호:** `BARK` / `CALM`은 시연용으로 그대로 둔다.
- **검증:** 이 가이드대로 고친 코드는 복사본에서 빌드까지 확인했다 (2026-11-07, BUILD SUCCESSFUL).

개 소리 라벨 (모델 안 번호): 69 Dog · 70 Bark · 71 Yip · 72 Howl · 73 Bow-wow · 74 Growling · 75 Whimper (dog)

## 진행 방법

- 0단계부터 차례로 한다. 단계 끝의 **✅ 확인**이 맞을 때만 다음으로 넘어간다. 안 맞으면 맨 아래 "막히면" 표를 본다.
- 코드 위치는 **⌘F로 찾을 글자**로 적었다. 괄호 안 줄 번호는 고치기 전 기준이다. 위에서 줄을 넣으면 조금씩 밀린다.

## 3단계. `BarkDetector.java` 만들기

**3-1.** Project 창에서 **app → java → ai.petcare.drive.car**를 우클릭 → **New → Java Class**를 고른다. 이름에 `BarkDetector`를 넣고 Enter.

**3-2.** 새 파일의 내용을 모두 지우고 (⌘A → Delete) 아래 코드를 붙여 넣는다.

```java
package ai.petcare.drive.car;

import android.content.Context;
import android.media.AudioRecord;
import android.os.Handler;
import android.os.Looper;
import android.util.Log;

import com.google.mediapipe.tasks.audio.audioclassifier.AudioClassifier;
import com.google.mediapipe.tasks.audio.audioclassifier.AudioClassifierResult;
import com.google.mediapipe.tasks.audio.core.RunningMode;
import com.google.mediapipe.tasks.components.containers.AudioData;
import com.google.mediapipe.tasks.components.containers.Category;
import com.google.mediapipe.tasks.core.BaseOptions;

import java.util.Locale;
import java.util.Set;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;

// 차량 마이크 소리를 약 1초마다 YAMNet으로 분류해 짖음을 알린다. 소리는 저장하지 않는다.
final class BarkDetector {

    interface Listener {
        void onBark();   // 짖음이 들림 (메인 스레드에서 불림)
        void onQuiet();  // QUIET_MS 동안 조용함 (메인 스레드에서 불림)
    }

    static final String TAG = "BarkDetector";
    static final Set<String> DOG = Set.of("Dog", "Bark", "Yip", "Howl", "Bow-wow", "Growling", "Whimper (dog)");
    static final float THRESHOLD = 0.3f;  // 개 소리 점수가 이 이상이면 들린 것으로 본다. Logcat 보며 조정
    static final int SAMPLE_RATE = 16000; // YAMNet 입력: 1초에 16000개
    static final int WINDOW = 15600;      // YAMNet이 한 번에 듣는 길이: 0.975초 분량
    static final long PERIOD_MS = 975;    // 듣는 길이와 같게 해야 소리가 밀려 쌓이지 않는다
    static final long QUIET_MS = 60_000;  // 이만큼 조용하면 진정한 것으로 본다 (시험할 땐 10_000)

    private final Context context;
    private final Listener listener;
    private final Handler main = new Handler(Looper.getMainLooper());
    private AudioClassifier classifier;
    private AudioRecord record;
    private ScheduledExecutorService loop;
    private int hits;                     // 개 소리가 연속으로 들린 횟수
    private long lastDogAt, lastReportAt;

    BarkDetector(Context context, Listener listener) {
        this.context = context;
        this.listener = listener;
    }

    // 모델을 열고 녹음을 시작한 뒤, PERIOD_MS마다 classifyOnce()를 부른다
    void start() {
        if (loop != null) return; // 이미 듣는 중
        AudioClassifier.AudioClassifierOptions options = AudioClassifier.AudioClassifierOptions.builder()
                .setBaseOptions(BaseOptions.builder().setModelAssetPath("yamnet.tflite").build())
                .setRunningMode(RunningMode.AUDIO_CLIPS)
                .setMaxResults(5)
                .build();
        classifier = AudioClassifier.createFromOptions(context, options);
        // 모노(1채널), 16kHz. 버퍼는 0.975초 분량 × 4바이트 × 2 (공식 예제와 같음)
        record = classifier.createAudioRecord(1, SAMPLE_RATE, WINDOW * 4 * 2);
        record.startRecording();

        hits = 0;
        lastDogAt = System.currentTimeMillis();
        loop = Executors.newSingleThreadScheduledExecutor();
        loop.scheduleAtFixedRate(this::classifyOnce, PERIOD_MS, PERIOD_MS, TimeUnit.MILLISECONDS);
        Log.d(TAG, "듣기 시작");
    }

    // 최근 0.975초 소리를 모델에 넣어 개 소리 점수를 구하고, 짖음/조용함을 판단한다
    private void classifyOnce() {
        try {
            AudioData audio = AudioData.create(AudioData.AudioDataFormat.create(record.getFormat()), WINDOW);
            audio.load(record); // 마이크에 쌓인 소리를 가져온다
            AudioClassifierResult result = classifier.classify(audio);

            float dog = 0;
            StringBuilder top = new StringBuilder();
            for (Category c : result.classificationResults().get(0).classifications().get(0).categories()) {
                top.append(String.format(Locale.US, "%s %.2f, ", c.categoryName(), c.score()));
                if (DOG.contains(c.categoryName())) dog = Math.max(dog, c.score());
            }
            Log.d(TAG, String.format(Locale.US, "dog=%.2f | %s", dog, top));

            long now = System.currentTimeMillis();
            if (dog >= THRESHOLD) {
                hits++;
                lastDogAt = now;
            } else {
                hits = 0;
            }

            // 2번 연속(약 2초) 들려야 짖음으로 본다. 알린 뒤 3초는 다시 알리지 않는다
            if (hits >= 2 && now - lastReportAt > 3000) {
                lastReportAt = now;
                Log.d(TAG, "→ 짖음");
                main.post(listener::onBark);
            } else if (now - lastDogAt > QUIET_MS) {
                lastDogAt = now; // 한 번 알리고 다시 센다
                Log.d(TAG, "→ 조용함");
                main.post(listener::onQuiet);
            }
        } catch (RuntimeException e) {
            // 여기서 예외가 밖으로 나가면 반복이 소리 없이 멈춘다. 로그만 남기고 다음 차례에 다시 듣는다
            Log.e(TAG, "분류 실패", e);
        }
    }

    // 녹음과 모델을 닫는다
    void stop() {
        if (loop == null) return;
        loop.shutdownNow();
        try {
            loop.awaitTermination(1, TimeUnit.SECONDS); // 돌던 판단이 끝난 뒤 닫는다
        } catch (InterruptedException ignored) {
        }
        loop = null;
        record.stop();
        record.release();
        classifier.close();
        Log.d(TAG, "듣기 멈춤");
    }
}
```

**3-3.** 붙여 넣은 코드를 위에서부터 읽어 본다. 하는 일은 세 가지뿐이다.

| 부분 | 하는 일 |
|---|---|
| 상수 | 기준값 모음. 시험하면서 바꿀 것은 `THRESHOLD`와 `QUIET_MS` 두 개뿐이다 |
| `start()` | 모델을 열고 녹음을 시작한 뒤, 0.975초마다 `classifyOnce()`를 부르게 한다 |
| `classifyOnce()` | 최근 0.975초 소리의 점수를 구해 로그에 찍는다. 짖음이면 `onBark()`, 1분 조용하면 `onQuiet()`를 부른다 |
| `stop()` | 반복을 멈추고 녹음과 모델을 닫는다 |

생각해 볼 것:
- **왜 0.975초마다일까?** YAMNet이 한 번에 듣는 길이가 0.975초다. 이보다 자주 하면 CPU를 더 쓴다. 이보다 드물게 하면 안 읽은 소리가 마이크에 쌓여 판단이 점점 늦어진다.
- **왜 2번 연속일까?** 한 번만 보면 문 닫는 소리나 박수도 개 소리로 잘못 볼 수 있다. 대신 아주 짧게 한 번 짖으면 놓친다. 달이 소리로 시험해 보고 정한다.
- **왜 `main.post(...)`를 쓸까?** `classifyOnce()`는 별도 스레드에서 돈다. 화면은 메인 스레드에서만 바꿀 수 있어서 넘겨준다.

✅ 확인: 빨간 줄이 없다. `com.google.mediapipe`로 시작하는 줄들이 빨가면 1단계 Sync가 안 된 것이다.

**5-5.** 맥에 대고 말을 해 본다.

✅ 줄이 `Speech 0.8…`처럼 바뀌면 마이크가 연결된 것이다. 계속 `Silence`뿐이면 0단계로 돌아간다.

**5-6.** 짖는 소리를 3초 넘게 튼다.

✅ `dog=` 값이 오르고 `→ 짖음`이 찍히며, 화면이 ③ 달래는 중으로 바뀐다 (숫자는 예시):

```
D  dog=0.81 | Dog 0.81, Animal 0.78, Domestic animals, pets 0.70, Bark 0.55, ...
D  dog=0.77 | ...
D  → 짖음
```

**5-7.** 짖는 소리를 끄고 기다린다. ③에서 나오는 안정 음악이 맥 스피커로 나와 `Music`으로 찍히는 것은 정상이다.

✅ 10초쯤 뒤 `→ 조용함`이 찍힌다. 화면은 ② 대기로 돌아오고, 위에 "진정했어요 · 짖음 N회, …"가 보인다.

**5-8.** 잘못 반응하는지 본다. 아래 소리를 각각 5초씩 내고, 그동안 가장 높았던 `dog=` 값을 적는다. 짖는 소리 말고는 ③으로 넘어가면 안 된다.

| 소리 | 가장 높은 dog 점수 | ③으로 갔나 |
|---|---|---|
| 짖는 소리 (유튜브) | | 가야 함 |
| 사람 말소리 | | |
| 박수 | | |
| 음악 (노래) | | |
| 문 닫는 소리, 책상 두드리기 | | |
| 고양이 소리 (유튜브) | | |

**5-9.** 기준값을 정한다. 짖는 소리 점수와 나머지 소리 점수 사이에 `THRESHOLD`를 둔다.
- 예: 짖음이 0.5~0.9이고 나머지가 0.1 아래면 0.3 그대로 둔다.
- 짖음을 놓치면 내리고, 다른 소리에 반응하면 올린다.

**5-10.** 위쪽 **펫케어 끝내기**를 누른다.

✅ `듣기 멈춤`이 찍히고, 그 뒤로 `dog=` 줄이 더 나오지 않는다.

**5-11.** `QUIET_MS`를 `60_000`으로 되돌린다.

## 알아 둘 것 (발표 질문 대비)

- **실제 차량 마이크:** Pleos 차량에서 외부 앱이 차량 마이크를 쓸 수 있는지는 확인하지 못했다. Pleos 개발자 문의(partnership@pleos.ai)로 물어볼 수 있다.
- **앱이 화면에서 내려가면:** 안드로이드가 마이크를 막아 빈 소리만 들어온다. 그래서 펫케어 중에는 앱이 화면에 떠 있어야 한다. 화면 없이도 들으려면 나중에 마이크용 포그라운드 서비스로 옮긴다.
- **시동을 끄면:** Suspend 모드로 들어가 녹음도 멈춘다. 펫케어는 차가 켜진 채(펫 모드·유틸리티 모드) 동작하는 것을 전제로 한다.
- **APK 크기:** MediaPipe가 CPU 4종류용 파일을 함께 넣어 APK가 19MB에서 72MB로 커진다. 차량 CPU 종류가 확인되면 (arm64로 예상) `abiFilters 'arm64-v8a'` 한 줄로 약 35MB까지 줄일 수 있다.
