# 10/28 온라인 설명회 질문 목록

우선순위 순. ★ = 답에 따라 기획이나 개발 방향이 바뀌는 질문.

## 0. 핵심 질문 (이것부터)
> ★ 차량 펫모드가 켜진 주차 상태에서, **3rd party 앱에게** ① 화면 실행 ② 마이크 사용 ③ 인터넷 통신 권한이 **허용되나요?**
> - 차량 시스템은 할 수 있지만 3rd party 앱에는 막혀 있다면, 공모전에서는 에뮬레이터 시연과 "정책 개방 시 적용" 기획으로 인정되나요?
> - Playground의 "제휴 계약 필요" 항목처럼, 수상 후 협의를 통해 열릴 가능성이 있는 권한인가요?

## 1. 앱 실행 환경 (컨셉 성립 여부)
1. ★ 시동 OFF 또는 주차(P단) 상태에서 3rd party 앱이 계속 실행될 수 있나요? 현대 펫모드처럼 공조가 유지되는 상태에서 백그라운드 서비스 동작이 가능한가요?
2. ★ 주차 중 앱이 차량 마이크로 소리를 계속 들을 수 있나요? (짖음 감지용 상시 녹음, 온디바이스 처리)
3. 주차 중에도 차량 네트워크(LTE)가 연결되어 있어 외부 서버(Firebase 등)와 통신할 수 있나요?
4. 3rd party 앱이 기존 차량 펫모드의 켜짐 상태를 조회하거나 연동할 수 있나요?

## 2. SDK 사용 범위
5. ★ Playground에 Vehicle Control, STT, TTS, FusedLocation SDK가 "준비 중"으로 되어 있습니다. 공모전 기간에 사용 신청이 가능한가요? 불가능하다면 에뮬레이터에서 구현한 것으로 심사해 주시나요?
6. ★ HVAC 온도 설정, 창문 개폐, 앰비언트 라이트 제어 같은 제어 API를 공모전 출품작에 써도 되나요? 실차 탑재 시 승인 가능성이 낮은 권한이면 감점 요인인가요?
7. 에뮬레이터에서 일반 `android.car.permission.*`이 아닌 `pleos.car.permission.*`이 필요했습니다. 도메인별 권한 목록이 정리된 문서가 있나요?
8. 앱에서 외부 라이브러리(TensorFlow Lite, WebRTC, Firebase SDK) 사용에 제한이 있나요?

## 3. 심사·제출
9. ★ 차량 앱과 함께 동작하는 스마트폰 앱(보호자 앱)도 개발 산출물로 인정되나요? GitHub에 함께 올리면 되나요?
10. 1차 가산점은 "시연 영상만" / "영상 + GitHub" / "영상 + GitHub + APK" 처럼 단계가 나뉘나요? 영상은 에뮬레이터 녹화로 충분한가요?
11. 기획서에 "준비 중" SDK를 활용 계획으로 써도 기술 활용성 점수에 반영되나요?
12. 2차 PT 시연은 개인 노트북의 에뮬레이터로 하나요, 아니면 현장에 실차나 시연 장비가 준비되나요? 발표 시간은 얼마인가요?
13. 2차 PT 심사 기준은 언제 공개되나요?

## 4. 참가 부문
- ★ 졸업자 1명과 대학생 1명으로 구성된 혼합 팀은 대학생 부문과 일반 부문 중 어디로 지원해야 하나요? 대표자가 대학생이면 대학생 부문이 가능한가요?

## 5. 기타
- Vehicle Data API(현재 유럽 전용)의 국내 지원 계획이 있나요?
14. 실차(또는 HW 시뮬레이터)에서 테스트할 기회가 있나요?
15. 기획서 분량 제한이 없다고 되어 있는데, 이미지(화면 시안, 구조도)를 본문에 넣어도 되나요?
