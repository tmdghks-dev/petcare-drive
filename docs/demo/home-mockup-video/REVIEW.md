# REVIEW: '내 차' 홈 화면 시안 영상

세로 1080×1920, 30fps, 8.8초, 소리 없음. 시안 이미지(`ref/mockup.png`) 한 장을 화면으로 다시 만들고, 화면이 하나씩 채워지는 과정을 보여 준다.

## 정한 것
- 세로 영상: 시안이 폰 화면이라 폰이 화면을 거의 채우게 했다. 숏폼(세로) 제출에도 쓸 수 있다.
- 카메라는 고정하고 UI만 움직인다: 차 등장 → 연결 상태 → 배터리 82%·312km 숫자 증가 → 타일 3개(온도 증가, 문 잠김과 함께 전조등 두 번 깜빡임, 위치 핀) → 최근 활동 → 하단 탭 → 알림 종 흔들림과 파란 점.
- 차는 시안 이미지에서 macOS Vision으로 배경을 지워 잘라냈다(`tools/cutout.swift`, `assets/car.png`).
- 위치·크기·색은 `tools/compare.py`로 시안과 같은 좌표에서 비교했다. 요소 대부분이 2px 안에서 맞는다.

## 시안과 다르게 한 것
- 회색 글자(타일 이름, 최근 활동 시간, 하단 탭 이름, 마지막 연결) 색을 시안보다 조금 진하게 했다. 시안 색 그대로면 명암비가 WCAG AA(4.5:1)에 못 미친다.
- 최근 활동 시간 순서(14:15 → 14:23 → 13:50)는 시안 그대로 두었다.

## 확인한 것 / 못 한 것
- `hyperframes check` 통과. 경고 2개는 일부러 둠:
  - `font_face_local_only`: 한글 글꼴은 이 Mac의 Apple SD Gothic Neo를 쓴다. 다른 컴퓨터나 클라우드에서 렌더하면 글꼴이 바뀐다.
  - `text_below_floor`: 폰 UI의 작은 글자(23~25px)가 영상 기준 28px보다 작다. 시안 비율을 지키려고 그대로 두었다.
- 장면별 스냅샷과 폰 크기 시트를 눈으로 확인했다. 최종 프레임은 시안과 나란히 놓고 비교했다.
- 소리는 없다.

## 더 시간이 있다면
- 가장 약한 부분: 0~0.15초 첫 프레임은 머리말만 있고 아래가 비어 있다.
- 다른 화면(제어, 위치) 시안이 있으면 탭을 눌러 넘어가는 장면을 이어 붙일 수 있다.
