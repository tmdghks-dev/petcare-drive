# 펫케어 드라이브 숏폼 스토리라인 (9:16, 35~45초)

공통: 1080×1920 · 30fps · 실제 앱 화면(Pleos 에뮬레이터·보호자 폰 녹화)만 사용 · 한국어 내레이션(Mac 유나, 무료) + 앱 안정 음악 · 자막 상시 표시(무음 시청 대비)
한 가지 기억할 것: "차에 두고 내려도, 차가 먼저 알아듣고 달래 준다"

## A. 달이의 15분 (추천)
- 장치·형식: 하루의 한 순간 + 한 화면이 계속 재구성되는 원테이크
- 내용: 휴게소에 달이를 두고 내린 15분을 시계로 따라간다. "혼자 남은 지 3분" 시계가 흐르고, 짖는 소리가 파형으로 터지면 차 화면이 크게 밀고 들어와 달래기 시작하고, 같은 순간 보호자 폰에 알림이 내려온다.
- 첫 2초: 달이 얼굴이 화면 70%를 채운 채 "차에 혼자 남은 지 3분" 타이머가 째깍 넘어가고, 큰 질문 "짖으면 어떡하지?"
- 비트: 훅(달이+타이머) → 짖음 파형 → 차가 달래는 화면 펀치인 → 폰 푸시 내려옴 → 폰에서 온도 내림 → 차 배너 → 위험 경보 → 진정 완료 15분 → 엔드카드
- 룩: 밝은 회색 바탕 #F1F4F6, 잉크 #202833, 포인트 #087DB5는 한 화면에 한 단어만, 큰 고딕(AppleSDGothicNeo Heavy 120px), 실제 앱 화면을 폭 90%로 크게 + 부드러운 그림자
- 소리: 유나 내레이션이 시계, 안정 음악 바닥, 장면 전환에만 휙 소리

## B. 소리가 화면이 된다 (과감한 안)
- 장치·형식: 기능이 곧 훅 + 물체가 다음 물체가 되는 연쇄
- 내용: 실제 짖음 소리의 파형이 화면을 가로지르고, 그 파형이 차 화면으로 빨려 들어가 파란 조명이 되고, 조명이 알림 카드가 되어 폰으로 떨어지고, 알림이 온도 다이얼이 된다. 컷 없이 모양이 이어진다.
- 첫 2초: 화면 가운데 굵은 파형이 "멍!" 소리에 맞춰 튀고, "이 소리를"
- 비트: 파형 → 차 화면(달래는 중) → 파란 조명 → 알림 카드 → 폰 → 온도 다이얼 → 에어컨 배너 → 엔드카드
- 룩: 같은 밝은 바탕, 파형·조명만 #087DB5, 굵은 타이포가 화면을 가로질러 크게
- 소리: 실제 짖는 소리로 시작, 음악은 차가 달래기 시작할 때 들어옴

## C. 보호자 시점
- 장치·형식: 전과 후 + 여러 화면이 하나로 모임
- 내용: 식당에 앉은 보호자의 폰 화면에서 시작. 전: 아무 정보 없이 "괜찮을까…"만. 후: 펫케어 드라이브 폰 화면에 실시간 온도·"달래는 중"·푸시가 차례로 뜨고, 마지막에 차 화면과 폰 화면이 한 장면으로 합쳐진다.
- 첫 2초: 폰 화면 가득 "괜찮을까…" 입력 중인 메모와 흐려진 차 사진
- 비트: 불안한 폰 → 앱 실행 → 실시간 상태 → 짖음 푸시 → 온도 조절 → 차 화면과 합쳐짐 → 엔드카드
- 룩: 폰 화면이 주인공(화면 높이 85%), 차 화면은 마지막에만
- 소리: 처음엔 거의 무음, 앱이 열리며 음악 시작
