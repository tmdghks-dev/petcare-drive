# 기능 명세

진행 순서: **① 기능 나열(이 문서) → ② 기능별 UI 설계 → ③ 개발**

- 단계: **MVP** = 11/15 1차 접수 전 / **2차** = 12/3 PT 전 / **로드맵** = 기획서에만
- 상태: ✅ 완료 · 🟡 일부(대체·데모) · ⬜ 미구현 · ⏳ SDK 미공개(Coming Soon)
- UI: 이 기능에 필요한 화면. **기존** = 이미 있는 화면에 추가 / **신규** = 새로 설계

## 1. 차량 앱 (Pleos)

| ID | 기능 | 설명 | 기술 / SDK | 단계 | 상태 | UI |
|---|---|---|---|---|---|---|
| C-01 | 함께 탈 아이 선택 | 출발 전 오늘 탈 반려견 선택, 여러 마리 가능 | - | MVP | 🟡 목록이 앱에 고정 | 기존: 아이 선택 |
| C-02 | 폰 연결 | 차량 화면 QR을 폰으로 찍어 연결 | Firebase | MVP | ⬜ | 신규: 연결 화면(QR) |
| C-03 | 펫케어 대기 | 반려견 사진, 실내 온도·배터리·유지 시간·도어 표시 | HVAC, EvBattery, Door | MVP | 🟡 도어는 에뮬레이터 미지원 | 기존: 대기 |
| C-04 | 주변인 안심 안내 | "반려견이 안전하게 보호되고 있어요" 문구로 오해·신고 방지 | - | MVP | ✅ | 기존: 대기 하단 |
| C-05 | **짖음 감지** | 마이크로 짖음·낑낑거림 감지 (온디바이스) | 마이크, YAMNet | MVP | ⬜ adb 신호로 대체 중 | 기존: 대기 상단 "짖음 감지 켜짐" |
| C-06 | 진정 동작 동시 실행 | 짖으면 보호자 알림 + 조명 + 안정 음악을 한 번에 | Light, MediaPlayer | MVP | 🟡 음악 ✅ / 조명 ⏳ / 알림 ⬜ | 기존: 진정 중 |
| C-07 | 보호자 목소리·영상 재생 | 폰에서 보낸 목소리(또는 미리 등록한 것)를 차에서 재생 | Firebase Storage | MVP | ⬜ | 기존: 진정 중에 "보호자 목소리" 줄 추가 |
| C-08 | 진정 완료 요약 | 짖음 횟수, 진정 시간, 혼자 있던 시간 | - | MVP | ✅ | 기존: 진정 완료 |
| C-09 | 차량 상태 업로드 | 온도·배터리·도어·위치를 주기적으로 서버에 올림 | Firebase RTDB, FusedLocation | MVP | ⬜ | 없음 (백그라운드) |
| C-10 | 위험 경보 | 온도가 적정 범위를 벗어나거나 배터리가 부족하면 경보 | HVAC, EvBattery | MVP | ⬜ | 기존: 대기에 경고 상태 추가 |
| C-11 | 도착 시 펫케어 제안 | 목적지 도착하면 "달이를 두고 내리시나요?" | NaviHelper | MVP | ⬜ | 신규: 제안 팝업 |
| C-12 | 음성 실행 | "펫케어 켜줘" | STT | 2차 | ⏳ | 없음 (음성) |
| C-13 | 원격 명령 실행 | 폰에서 보낸 온도 설정·창문 환기 실행 | HVAC·Window 제어 | 2차 | ⏳ | 기존: 진정 중/대기에 결과 표시 |
| C-14 | 주행 중 케어 | 급제동 시 멀미 주의 안내, 1~2시간마다 휴식 안내, 안전 창문 | Brake, DrivingMode, NaviHelper, TTS, Window | 2차 | ⬜ / ⏳ | 신규: 주행 중 화면 |
| C-15 | 두고 내림 경고 | 반려견을 태운 채 하차하면 경고 | Door | 2차 | ⬜ | 신규: 경고 팝업 |
| C-16 | 실시간 통화 | 보호자와 차량 스피커로 통화 | WebRTC | 2차 | ⬜ | 신규: 통화 중 화면 |

## 2. 보호자 앱 (Flutter)

| ID | 기능 | 설명 | 기술 | 단계 | 상태 | UI |
|---|---|---|---|---|---|---|
| P-01 | 차량 연결 | 차량 화면 QR 스캔으로 연결 | Firebase, 카메라 | MVP | ⬜ | 신규: 시작·QR 스캔 |
| P-02 | 반려견 프로필 | 여러 마리 등록·수정 (이름, 사진, 견종, 나이, 적정 온도, 분리불안) | Firebase RTDB | MVP | 🟡 앱 안에서만 저장, 사진 선택 없음 | 기존: 프로필 |
| P-03 | 목소리 녹음·등록 | "금방 올게" 같은 목소리 미리 녹음 | 마이크, Firebase Storage | MVP | ⬜ | 신규: 목소리 녹음 |
| P-04 | 홈 대시보드 | 온도·배터리·도어·위치, 오늘 기록 | Firebase RTDB | MVP | 🟡 데모 데이터 | 기존: 홈 |
| P-05 | 짖음 푸시 알림 | 차에서 짖음이 감지되면 폰에 푸시 | FCM, Cloud Functions | MVP | ⬜ | 없음 (OS 알림) |
| P-06 | 짖음 알림 상세 | 차에서 실행 중인 진정 동작, 대응 버튼 | - | MVP | 🟡 데모 데이터 | 기존: 짖음 알림 |
| P-07 | 목소리 들려주기 | 버튼 누르면 차에서 즉시 재생 (그 자리 녹음도 가능) | Firebase | MVP | ⬜ | 기존: 홈·짖음 알림 버튼 |
| P-08 | 위험 경보 | 온도·배터리 이상 시 긴급 푸시 | FCM | MVP | ⬜ | 신규: 경보 상세 (또는 짖음 알림 화면 재사용) |
| P-09 | 원격 제어 | 온도 조절, 창문 환기 | Firebase → C-13 | 2차 | ⬜ | 신규: 원격 제어 |
| P-10 | 실시간 통화 | 차량과 음성 통화 | WebRTC | 2차 | ⬜ | 신규: 통화 중 |
| P-11 | 분리불안 리포트 | 날짜별 짖음 횟수, 진정 시간 | Firebase RTDB | 2차 | 🟡 자리만 | 기존: 리포트 탭 |
| P-12 | iOS 지원 | iOS 빌드와 푸시 | APNs | 2차 | 🟡 빌드만 확인 | 없음 |
