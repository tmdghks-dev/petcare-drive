# 기능 명세

진행 순서: **① 기능 나열(이 문서) → ② 화면 설계 (`docs/design/ui-v2/`) → ③ 개발**

## 설계 원칙 (2026-11-07)
- **동물을 위한 앱:** 모든 화면은 "반려견이 지금 괜찮은가?"와 "아니면 무엇을 하면 되나?"에만 답한다.
- **기본 앱과 겹치지 않는다:** 문 잠금, 차 위치, 주행 가능 거리, 창문 일반 조작, 경적은 넣지 않는다.
- **차 정보는 반려견 기준으로만:** 실내 온도 → 달이 적정 범위 안인지, 배터리 → 펫케어를 얼마나 더 유지하는지.
- **예외:** 원격 온도 조절과 환기(창문 2cm)는 넣는다.
- **상태는 3가지:** 차분해요(파랑) · 달래는 중(주황) · 위험(빨강). 두 앱이 같은 말과 색을 쓴다.

## 기본 펫 모드보다 나은 점
기본 펫 모드는 실내 온도 유지와 화면 안내 문구까지다. 우리는 그 위에 다음을 더한다.
1. **짖음 감지 → 자동으로 달래기:** 조명, 안정 음악, 보호자 목소리 (C-05~C-07)
2. **보호자 목소리를 원격으로 들려주기** (P-07)
3. **반려견별 기준으로 미리 경고:** 아이마다 다른 적정 온도, 배터리로 펫케어를 얼마나 더 버틸지 (C-10, P-08)
4. **위험하면 차가 스스로 환기하고, 지나가는 사람에게 할 일을 알려 준다** (C-17, 차 ④)
5. **도착하면 먼저 물어본다:** 펫 모드 켜는 걸 잊지 않게 (C-11)

## 2. 보호자 앱 (Flutter)

| ID | 기능 | 설명 | 기술 | 단계 | 상태 | 화면 |
|---|---|---|---|---|---|---|
| P-01 | 차량 연결 | 차 화면의 QR을 찍어 연결 → 아이 정보 입력 → 홈 | Firebase, 카메라 | MVP | ⬜ | 폰 ⑦ |
| P-02 | 반려견 프로필 | 여러 마리 등록·전환, 이름·사진·견종·나이, 적정 온도 범위, 분리불안, 연결된 차 | Firebase RTDB | MVP | 🟡 앱 안에서만 저장, 사진 선택 없음 | 폰 ⑥ |
| P-03 | 목소리 녹음·등록 | 목소리 녹음과 미리 듣기, 짖으면 자동으로 틀 목소리 고르기 | 마이크, Firebase Storage | MVP | ⬜ | 폰 ⑤ |
| P-04 | 홈 | 상태 한 줄, 실내 온도(적정 여부·설정 온도), 펫케어 유지 시간, 오늘 기록 3줄 | Firebase RTDB | MVP | 🟡 데모 데이터, 새 화면 반영 전 | 폰 ① |
| P-05 | 짖음 푸시 알림 | 차에서 짖음이 감지되면 폰에 푸시 | FCM, Cloud Functions | MVP | ⬜ | 없음 (OS 알림) |
| P-06 | 짖음 알림 상세 | 차가 이미 하고 있는 일, 목소리 들려주기·온도 조절 버튼 | - | MVP | 🟡 데모 데이터 | 폰 ③ |
| P-07 | 목소리 들려주기 | 홈·알림의 버튼, 목소리 탭의 '보내기' → 차에서 바로 재생 | Firebase | MVP | ⬜ | 폰 ① ③ ⑤ |
| P-08 | 위험 경보 | 무음이어도 울리는 강한 푸시, 위험 알림 화면에서 온도 낮추기 한 번에 | FCM | MVP | ⬜ | 폰 ④ |
| P-09 | 온도·환기 | 설정 온도 맞추기, 창문 2cm 환기 켜기·끄기 | Firebase → C-13 | MVP | ⬜ (차 적용은 ⏳) | 폰 ② |
| P-10 | 실시간 통화 | 차량과 음성 통화 | WebRTC | 2차 | ⬜ | 신규 (2차) |

## 3. 서버 (Firebase) — 기능 구현을 마친 뒤 연결

| ID | 기능 | 쓰는 곳 |
|---|---|---|
| S-01 | 차량·폰 연결 (carId 공유) | C-02, P-01 |
| S-02 | 차량 상태 실시간 DB | C-09, P-04 |
| S-03 | 이벤트 → 푸시 (Cloud Functions + FCM, 폰만) | C-06, C-10, P-05, P-08 |
| S-04 | 목소리 파일 저장 (Storage) | C-07, P-03, P-07 |
| S-05 | 원격 명령 전달: 목소리 재생, 설정 온도, 환기 | C-07, C-13, P-07, P-09 |

Pleos에는 구글 Play 서비스가 없어 차는 FCM 푸시를 받지 못한다. 폰 → 차 명령(S-05)은 차가 RTDB를 구독해서 받는다.

## 4. 넣지 않는 것
| 항목 | 이유 |
|---|---|
| 도어 잠금 표시, 원격 잠금 해제 | 기본 앱에 있다. 자동 해제는 도난·탈출 위험 |
| 차 위치, 주행 가능 거리 | 기본 앱에 있다 |
| 창문 일반 조작 | 기본 앱에 있다. 환기용 2cm만 넣음 (C-13, C-17) |
| 경적, 전조등 깜빡임 | 경적은 SDK에 없고 차 안 강아지에게 큰 스트레스. 전조등은 빼기로 함 |
| 음성 실행 (C-12) | 간단하게 하려고 뺌 |
