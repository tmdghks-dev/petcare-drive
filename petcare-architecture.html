Firebase 데이터 구조

두 앱이 지켜야 할 공통 약속입니다. 1주차에 함께 확정하세요.

vehicles/{carId}/
  status      temp, humidity, battery,
              careMinutesLeft, locked, lat, lng,
              mode: "idle" | "care" | "driving",
              updatedAt
  events/     {id}: type: "bark" | "temp" | "battery",
              stage: 1~3, at
  commands/   {id}: action: "setTemp" | "vent" | "playVoice",
              value, done
  profile     name, breed, age, size,
              brachy, tempMin, tempMax
  reports/    {date}: aloneMin, barkCount, calmSec
storage/{carId}/
  voice/*.m4a   video/*.mp4   // 보호자 음성·영상

차량과 폰 연결은 처음에 차량 화면에 QR 코드를 띄우고 폰으로 스캔해 carId를 공유하는 방식이 가장 간단합니다. Cloud Functions를 쓰려면 Firebase Blaze 요금제(카드 등록 필요)가 필요하지만, 무료 사용량 안에서는 사실상 비용이 들지 않습니다.

역할 분담

두 사람은 Firebase 데이터 구조만 맞추면 따로 개발할 수 있습니다.

A · 차량 앱Pleos Connect

  • 에뮬레이터 세팅, Vehicle SDK 연동
  • YAMNet 짖음 감지, 단계별 진정, 안심 화면
  • 상태 업로드, 이벤트 기록, 음성 재생
  • 2차: 원격 명령 실행, 주행 케어, 통화

B · 폰 앱 + Firebase + 기획Flutter

  • Firebase 프로젝트, Cloud Functions 푸시
  • 대시보드, 알림, 프로필, 음성 녹음·전송
  • 기획서, 통계 근거, 시연 영상, 숏폼
  • 2차: 원격 제어, 리포트, 통화, iOS 빌드·푸시
